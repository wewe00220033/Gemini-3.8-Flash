## 🎯 ملخص المتطلبات الأساسية (الجوهر):
1. **القاموس المخصص (`glossary.json`):** شلبي = ChatGPT، سانتا = Sonnet، أوبوس = Opus، جرافيك = Antigravity.. قابل للإدارة من تليجرام.
2. **تعديل الـ Prompt من البوت:** إضافة وتعديل القواعد والأمثلة دون لمس السورس كود.
3. **لوحة التحكم (`/panel`):** أزرار تفاعلية ونظام صفحات (Pagination) لعرض المفاتيح والقاموس.
4. **نظام الرسالتين لكل فويس:** رسالة خام فورية مع ديباجة تفريغ + رسالة منظمة مصاغة حسب التخصص (DevOps، معلم، شيخ، دكتور).
5. **الأرشيف الدائم (`ALL.md`):** حفظ كل التفريغات على السيرفر بصيغة Markdown وتنزيلها بضغطة زر.
6. **جلسات ومحادثات مسماة (`sessions/`):** بدء محادثة باسم معين، استكمال محادثات سابقة، واقتراح أسماء المحادثات ذكياً عبر AI.
7. **سجلات دوارة كالكاميرات (`logs/`):** تدوير وحذف أوتوماتيكي بعد 7 أو 14 يوماً.
8. **الذاكرة والسياق:** ذاكرة ذكية اختيارية أثناء الجلسات المفتوحة.
9. **قاطع الدائرة ضد 503 واللاج:** معالجة فورية وتخطي سريع دون الحاجة لتدخل المالك.
