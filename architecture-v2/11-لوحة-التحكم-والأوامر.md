# 11 — لوحة التحكم (`/panel`) والأوامر وتجربة الاستخدام

> **الهدف:** "لوحة تحكم كاملة من تليجرام" [م1] بأزرار inline [قرار-مالك]، مع التزام **Buttons = Commands** (كل زر له أمر نصي مكافئ) حتى لا يُحبس المالك لو تعطلت الأزرار.
> **المصادر:** [م1]، [ج1] M07 شجرة اللوحة + FSM + whitelist الإعدادات، [ج8] parity، [ج4/5/6] أوامر الجلسات/الأوضاع/القاموس، [ج3] `setMyCommands`، الكود (لا `callback_query` handler حالياً).

---

## 1. المتطلب التقني الأول: معالجة `callback_query`
حلقة البوت (`telegram_bot.py` l.429) تقرأ `update["message"]` فقط. يجب:
- `allowed_updates=["message","callback_query"]` في `getUpdates`.
- `answerCallbackQuery` **فوراً** (< 1ث وإلا يظهر تحميل دائم) ثم المعالجة.
- `editMessageText` لتحديث نفس الرسالة بدل إغراق الشات.
- `callback_data` ≤ **64 بايت** → ترميز مضغوط: `p:k:2` (panel/keys/page2)، `g:d:g_004` (glossary/delete/id)، `s:r:ab12` (session/resume/id8). **لا نصوص عربية في callback_data**.
- حماية: callback من `chat_id` غير المصرح به يُتجاهل (نفس فلتر الرسائل).

## 2. شجرة اللوحة [ج1 M07 — مُنقّحة]

```
/panel
├─ 📊 الحالة          → نفس /status + النبض + الطابور
├─ 🔑 المفاتيح        → قائمة 5/صفحة [⬅️ ➡️] → مفتاح: [✏️ تسمية] [🗑 حذف] [🏷 مجموعة مشروع]
├─ 🎛 وضع الإرسال     → ◉ مزدوج ○ خام ○ منظم
├─ 🎭 الدور           → قائمة الأدوار (الحالي ✓) + [➕ دور جديد]
├─ 🗂 الجلسات         → [➕ جديدة] [▶️ استئناف] [⏹ إنهاء] [📥 تصدير]
├─ 📖 القاموس         → قائمة 5/صفحة + [➕ إضافة]
├─ 🧠 السياق          → ◉ تلقائي ○ بسيط دائماً
├─ 🧾 السجلات         → [📄 اليوم] [⚠️ الأخطاء] [🔍 تتبع آخر فويس]
├─ 💾 النسخ           → [📦 نسخة الآن] [🔐 نسخة الأسرار] [🧪 اختبار استعادة]
├─ 🩺 الطبيب          → تشغيل /doctor
└─ ⚙️ إعدادات         → قائمة الإعدادات الآمنة فقط
```

### الترقيم (Pagination)
- `PANEL_PAGE_SIZE = 5` (المالك طلب 5 للجلسات والقاموس؛ [ج1] اقترح 8 — نوحّد على 5 ونجعله Config).
- الزر يعرض السياق: «إعداد Nginx (12 فويس)» [قرار-مالك ب].
- الصفحة في callback: `s:l:3` → الصفحة 3.

## 3. آلة الحالات للمعالجات متعددة الخطوات (FSM) [ج1]
- حالات: `idle`, `await_word_src`, `await_word_dst`, `await_session_name`, `await_role_desc`, `confirm_delete:<target>`.
- `FSM_TTL_SECONDS = 300` → انتهاء تلقائي مع رسالة "انتهت المهلة".
- `/cancel` في أي وقت.
- **الفويس أثناء FSM؟** يُعالج طبيعياً **ولا يُفسد** الحالة — الحالة تنتظر **نصاً** فقط.
- حالة واحدة فقط (مستخدم واحد) — في الذاكرة؛ لا تحتاج قرصاً.

## 4. الإعدادات من البوت — القائمة البيضاء [ج1 M08]
**يُسمح** عبر `/set <key> <value>` واللوحة:
`delivery_mode, role, context_mode, transcript_header_target, log_retention_days, panel_page_size, retry_budget_seconds, model_503_key_hops, backup_weekly_day, notify_on_start, progress_after_seconds`

**يُمنع نهائياً** (من Config/البيئة فقط): المفاتيح، التوكن، `WEB_ACCESS_TOKEN`, `DATA_DIR`, قائمة الموديلات، `TRANSCRIBE_WORKERS`.
- كل تغيير → `audit.log` + تأكيد يعرض القديم/الجديد.
- تحقق من النوع والمدى (`log_retention_days` 1–365).
- طبقتان: `Config` = الافتراضي، `settings.json` = التجاوز.

## 5. الأوامر الكاملة (المرجع الموحد)

| المجموعة | الأوامر | الحالة |
|---|---|---|
| أساسية | `/start /help /status /panel /cancel` | status/help موجودان |
| مفاتيح | `/keys /remove /rename /project_group` + لصق مفتاح | معظمها موجود |
| إرسال | `/mode /last /polish /retranscribe` | جديد |
| أدوار | `/roles /role <id> /role_<slug> /new_role /role_edit /role_del` | جديد |
| جلسات | `/sessions /new_session /resume /end /rename_session /merge_sessions /export` | جديد |
| قاموس | `/glossary /add_word /del_word /glossary_export` | جديد |
| تفاعلية (21) | `/quran /kids /lesson /next /repeat /summary /exit` | جديد — **ج4:** كانت ناقصة من جدول التكافؤ |
| سياق | `/context auto|simple` | جديد |
| سجلات | `/logs /trace /stats /find` | جديد |
| نسخ | `/backup /backup_secrets /snapshot /restore_test` | backup موجود (يتغير) |
| تشغيل | `/reset /doctor /queue /health` | reset موجود |
| مساعد | `/ask /chat /plan` | جديد (12) |

- `setMyCommands` عند البدء بقائمة **مختصرة** (≤ 12 أمراً أساسياً) — الباقي عبر `/help` واللوحة.
- `/help` مقسّم بالمجموعات؛ `/help جلسات` لمجموعة واحدة.

## 6. نصوص الواجهة
- بالعامية المصرية البسيطة كما هو الآن.
- كل زر ≤ 20 حرفاً حتى لا يُقتطع على الموبايل.
- التأكيد المزدوج للحذف: [🗑 حذف] → تتحول إلى [✅ متأكد] [❌ إلغاء] في **نفس الرسالة**.

## 7. مرفوض/مؤجل
| المقترح | المصدر | القرار |
|---|---|---|
| Reply keyboard (لوحة سفلية دائمة) | — | **مرفوض** [قرار-مالك: inline] |

> **تمييز (ج4):** `/role_quran` و`/role_kids` = **أدوار تفريغ/تنظيم** (06 §2) تغيّر برومبت الرسالة الثانية فقط. `/quran` و`/kids` = **أوضاع تفاعلية** (21) تغيّر سلوك البوت كله حتى `/exit`. أزرار اللوحة تعرض الاثنين في قسمين منفصلين كي لا يلتبسا.

## 8. معايير القبول (DoD)
1. كل `callback_data` ≤ 64 بايت (اختبار يولّد كل الأزرار).
2. كل زر له أمر نصي يفعل الشيء نفسه (اختبار parity على جدول الربط).
3. FSM تنتهي بعد TTL؛ فويس أثناءها لا يكسرها.
4. `/set` يرفض المفاتيح الممنوعة والقيم خارج المدى.
5. `answerCallbackQuery` يُستدعى لكل callback حتى عند الخطأ.
