# 21 — الأوضاع التفاعلية: مراجعة القرآن الكريم ومذاكرة الأطفال

> **لماذا ملف مستقل:** في الجولتين السابقتين عالجتُ القرآن والأطفال كـ **أدوار تنسيق** داخل 06. إعادة قراءة الشات (1226–1234، 1255–1258) تُظهر أن المالك يريد **حواراً**: يرسل تلاوة أو إجابة ابنه، والبوت **يحكم ويرد**. سلوك مختلف جذرياً عن "فرّغ ونظّم" ويحتاج حالة محادثة ومرجعاً للمقارنة.
> **المصادر:** [شات] 1226 ("أنا وابني… الصغير مش بيفهم كويس، قرآن الكريم")، 1230–1232 ("أبعت آيات… صح ولا غلط… يرد عليا… فلاش لايت 3.5 بالتفكير الماكس… التجويد، الأحكام، التشكيل")، 1234 ("وضع المعلم، يذاكر مع الواد: كده صح كده غلط").

---

## 0. قيد أخلاقي/هندسي يُقال للمالك أولاً

**النص القرآني لا يُترك لتقدير LLM.** الموديلات تخطئ في الآيات وتخلط المتشابهات وتُنشئ نصاً "يبدو قرآنياً". لذلك:
- **المرجع = مصحف نصي محلي** (بيانات مفتوحة: إملائي مبسّط + عثماني، مثل Tanzil، ~1.5MB) في `data/quran/`.
- **المطابقة برمجية** (تطبيع + محاذاة كلمات)، وflash-lite **يصوغ الملاحظة فقط** ولا يقرر الصواب.
- **ما يمكن مراجعته من نص:** الحفظ (نقص/زيادة/تقديم/تأخير/إبدال). **ما لا يمكن:** التجويد والمخارج والمدود — تحتاج تحليلاً صوتياً خارج نطاق التفريغ النصي. يُقال صراحة في رسالة بدء الوضع.

## 1. وضع مراجعة القرآن (`/quran`)

### 1.1 التدفق
```
/quran → "📖 وضع المراجعة. حدد [سورة + آية البداية] أو [تلقائي من أول آية تتلوها]"
  ├─ فويس تلاوة
  ├─ تفريغ (3.6 أساسي؛ طبقة A بوضع quran: "رسم إملائي، بلا تشكيل، بلا تعليق")
  ├─ تطبيع (همزات/ة/ى/إزالة التشكيل) للمسموع وللمرجع
  ├─ تحديد الموضع: غير محدد → بحث n-gram (أول 4 كلمات) في المصحف المطبّع
  ├─ محاذاة كلمات (difflib.SequenceMatcher على مستوى الكلمة) → قائمة فروق
  ├─ تصنيف: ناقصة / زائدة / مُبدَلة / تقديم-تأخير / تطابق كامل
  ├─ flash-lite (أقصى تفكير) يصوغ: "ما شاء الله — البقرة 255–257 ✅" أو
  │   "⚠️ آية 256: قلت «لا إكراه في الدين قد تبين» — ناقص «الرشد»…" + الآية الصحيحة بالرسم العثماني **من المرجع**
  ├─ أزرار: [🔁 أعد المقطع] [⏭ الآيات التالية] [📊 ملخص] [⏹ إنهاء]
  └─ يُسجَّل في الجلسة: المقطع، الأخطاء ونوعها (تقرير حفظ لاحق)
```

### 1.2 قواعد
- **لا يُعرض أبداً نص قرآني من مخرجات LLM**؛ المعروض من المرجع المحلي فقط.
- عتبة ثقة الموضع < 70% → "لم أتعرف على الموضع — حدد السورة" بدل تخمين.
- فويس غير قرآني في الوضع → "لا يبدو قرآناً؛ أخرج من الوضع؟ [نعم] [لا]".
- Config: `QURAN_REF_PATH`, `QURAN_MATCH_THRESHOLD=0.7`.
- الحصة: تفريغ واحد + نداء flash-lite واحد لكل مقطع.

### 1.3 مرفوض/مؤجل
| المقترح | القرار | السبب |
|---|---|---|
| تقييم التجويد/المخارج | **مرفوض صراحة** | يحتاج صوتاً لا نصاً؛ وعد كاذب |
| LLM يقرر صحة الآية بلا مرجع | **مرفوض** | §0 |
| مقارنة التشكيل | P3 | التفريغ لا يخرج تشكيلاً موثوقاً |
| قراءات غير حفص | P3 | مرجع واحد أولاً |

## 2. وضع مذاكرة الأطفال (`/kids`)

### 2.1 التدفق
```
/kids → "👨‍👦 وضع المذاكرة. ابعت الدرس كنص (أو /lesson <نص>) ثم خلي الطفل يقرأ/يجيب"
  ├─ نص الدرس (أو اختيار محفوظ: [درس 1] [درس 2]…)
  ├─ فويس الطفل
  ├─ تفريغ بطبقة A بوضع kids: "المتحدث طفل؛ النطق غير مكتمل؛ اكتب أقرب كلمة صحيحة؛ لا تصحح المعنى"
  ├─ flash-lite (أقصى تفكير) يقارن بالدرس: صحيح / خطأ / منسي
  ├─ رد تربوي: تشجيع → خطأ واحد أو اثنان فقط → سؤال متابعة بسيط
  ├─ أزرار: [⭐ برافو — التالي] [🔁 كرر الجزء ده] [📘 درس جديد] [⏹ إنهاء]
  └─ يُسجَّل: الدرس، النسبة التقريبية، الأخطاء المتكررة (تقرير أسبوعي للأب)
```

### 2.2 قواعد
- **لا لهجة قاسية**؛ البرومبت يفرض: تشجيع → تصحيح واحد → تشجيع.
- طول الرد ≤ 300 حرف.
- **الخصوصية:** صوت الطفل لا يُحفظ (`KEEP_AUDIO=0` ملزم)؛ النص في جلسة باسم الدرس.
- Config: `KIDS_MAX_REPLY_CHARS=300`, `KIDS_TONE=encouraging`.
- الدروس في `data/lessons/*.md` — قابلة للتصدير والتعديل (`/lesson_edit`).

## 3. المشترك بين الوضعين (بنية `tutor.py`)

| العنصر | التصميم |
|---|---|
| حالة الوضع | `STATE["mode"] = quran \| kids \| None` + السياق (السورة/الدرس) في `state/tutor.json` (يستمر بعد restart) |
| الخروج | `/exit` أو ⏹ أو أمر آخر (يسأل: "تخرج من وضع X؟") |
| الجلسات | الوضع **ينشئ جلسة تلقائياً** ("مراجعة قرآن 2026-10-25" / "درس: الضرب") — استثناء وحيد لقاعدة 08 §2، مبرَّر لأن الوضع إعلان نية |
| الطابور | نفس الطابور؛ يختلف فقط hook `post_transcribe(mode)` بعد التفريغ |
| Buttons = Commands | `/next` `/repeat` `/summary` `/exit` `/lesson` |
| الفشل | flash-lite فشل → التفريغ الخام + "تعذر التقييم الآن" — لا يُحجب شيء |
| الأمان | نص الدرس/الآية **بيانات** داخل محدِّدات في البرومبت؛ لا يُفسَّر كأمر |

## 4. اختبارات (DoD)
1. مطابقة قرآن: 5 حالات ذهبية (تطابق / ناقصة / زائدة / مُبدَلة / موضع مجهول) على `tests/fixtures/quran_mini.json` — **بلا شبكة**.
2. التطبيع: "إبراهيم/ابراهيم"، "الصلوة/الصلاة" يتطابقان.
3. عتبة 70%: نص عادي لا يُطابق موضعاً.
4. kids: الرد ≤ 300؛ البرومبت يحوي قيود اللهجة.
5. `tutor.json` يستمر بعد restart.
6. أمر مختلف أثناء الوضع يسأل أولاً.
