> **الهدف:** إغلاق الثغرات الحالية في الويب والنسخ، اختيار بنية تخزين **بسيطة ومتينة**، وضمان أن كل ميزة تُختبر قبل الدمج.
> **المصادر:** [ج1] مخاطر الويب + M15 أمان + M16 web parity + M17 اختبارات + خيارات التخزين، [ج3] SQLite/atomic/schema_version/feature flags/constitution، [ج2] mock provider + `/verify`، الكود (`web_service.py`, `key_manager.save`).

## 1. الأمان

### 1.1 ثغرات حالية (من الكود مباشرة — انظر 01 §3.3)
| # | الثغرة | الإصلاح | الأولوية |
|---|---|---|---|
| S1 | `WEB_ACCESS_TOKEN` فارغ → API مفتوح بالكامل | عند البدء: لو فارغ **وليس** `BIND_HOST=127.0.0.1` → **توليد توكن عشوائي** وطباعته + إرساله للمالك على تليجرام مرة واحدة. الوضع المفتوح يحتاج `WEB_ALLOW_OPEN=1` صريحاً | **P0** |
| S2 | التوكن في `?token=` (query string) | Header `X-Access-Token` أو Cookie `HttpOnly` بعد صفحة دخول بسيطة؛ query string يُقبل **فقط** لمرة واحدة لتحويله إلى cookie ثم redirect | P1 |
| S3 | `/api/reset` عبر GET | POST فقط | P1 |
| S4 | `/backup` يرسل `keys.json` | فصل `/backup` (بيانات) عن `/backup_secrets` (تأكيد مزدوج) — 09 §4 | **P0** |
| S5 | لا rate limit على الويب | عدّاد بسيط بالـ IP: 30 طلب/دقيقة لـ `/api/transcribe` — يحمي الحصة لو تسرب الرابط | P1 |
| S6 | الأسرار في السجلات | فلتر الحجب (09 §3) | **P0** مع السجلات |

### 1.2 مبادئ ثابتة
- **مستخدم واحد**: `ALLOWED_CHAT_ID` هو الحارس الأول؛ أي update من غيره يُتجاهل **بصمت** (لا رد — لا نكشف وجود البوت).
- `keys.json` 600 ✔ موجود. `settings.json`/`glossary.json` لا تحوي أسراراً.
- **لا تنفيذ أوامر نظام من تليجرام** (رفض `/term` و`/files` — 11 §7).
- **الأوامر الصوتية = prompt injection**: نص الفويس **بيانات فقط**، لا يُفسَّر كأمر أبداً. (يحسم تعارض [ج3] "voice-as-command").
- الأسرار تأتي من البيئة أولاً، `keys.json` ثانياً؛ لا تُطبع كاملة في أي مكان.

## 2. التخزين — JSON + Markdown + ndjson (لا SQLite الآن)

| الخيار | المزايا | العيوب | القرار |
|---|---|---|---|
| **MD + JSON + ndjson** | قابل للقراءة مباشرة، `/export` ترسله كما هو، صفر اعتماد، git-friendly | البحث خطي؛ لا معاملات | ✅ **المعتمد** للمرحلة 1–5 |
| SQLite | بحث سريع، معاملات، FTS5 | ملف ثنائي (التصدير يحتاج تحويلاً)؛ قفل الملف على بعض أنظمة الملفات الشبكية (Pterodactyl volumes) | ⏸ **مؤجل** — يُعاد النظر لو تجاوز `ALL.md` 50MB أو بطؤ `/find` > 2ث |
| Hybrid (MD + فهرس SQLite) | أفضل الاثنين | تعقيد مزامنة | ⏸ P3 |

### قواعد السلامة الإلزامية لكل ملف
1. **كتابة ذرية** مشتركة `atomic_write_json(path, data)` (تعميم `key_manager.save`) — `tmp → fsync → os.replace`.
2. **`schema_version`** في رأس كل JSON؛ دالة `migrate()` لكل ملف تبدأ بـ no-op.
3. **التحميل المتسامح**: ملف تالف → `*.corrupt-<ts>` + تحميل الافتراضي + إشعار المالك. **لا انهيار عند البدء أبداً**.
4. `.md` بـ append فقط؛ لا إعادة كتابة كاملة لملف كبير.
5. `DATA_DIR` فحص الاستمرارية (09 §6).
6. قفل `threading.Lock` لكل مخزن (worker + poller + web قد يكتبون معاً).

## 3. تكافؤ الويب (Web Parity) [ج1 M16]
- الويب الحالي يفرّغ ويعرض الحالة ويضيف مفتاحاً. المطلوب **ليس** نسخ اللوحة كاملة — المالك يستخدم تليجرام أساساً.
- **الحد الأدنى للتكافؤ:** `/api/transcribe` يمر عبر **نفس الـ pipeline** (قاموس → دور → تنظيم → أرشفة في `ALL.md` بوسم «ويب») حتى لا يصبح الويب مساراً "خاماً" مختلفاً. يعود `{raw, polished, session}`.
- `/health` يعرض نفس تقرير `/doctor` المحلي (JSON) — مفيد لمراقبة خارجية (UptimeRobot).
- واجهة الويب: إضافة عرض الجلسات والتصدير (قراءة فقط) — P2.
- الويب يعمل **ويب-فقط** لو لا توكن تليجرام (موجود) ✔.
- **(ج3، G27)** فشل إقلاع الويب (منفذ مشغول/محجوز/بلا صلاحية) → إشعار تليجرام **مرة واحدة** + ظهوره في `/status`؛ البوت يستمر بلا ويب. اليوم: لوج فقط.
- **(ج3، P2)** رفع ملفات كبيرة من الويب (> حد inline) → Gemini **Files API** (`media.upload` ثم مرجع `file_uri`) بدل base64 inline. مؤجل حتى يظهر طلب فعلي؛ الحد الحالي كافٍ لفويسات تليجرام (≤20MB).

## 4. الاختبارات (الحالي 110 → الهدف ≥ 200)

### 4.1 مصفوفة التغطية المطلوبة
| المجال | اختبارات جديدة أساسية |
|---|---|
| الشبكة (03) | heartbeat stall → إعادة إنشاء؛ ReadTimeout → Session جديدة؛ FIFO ترتيب + تحميل متسلسل؛ retry تحميل ×3؛ المهلات tuples |
| Failover (04) | 503 key-hop؛ سلم القفل؛ انتظار `earliest_open`؛ ميزانية؛ `project_group`؛ circuit persist |
| القاموس (05) | سوابق، تطبيع، `context_rules`، scope، أطول أولاً |
| البرومبت (06) | طول A ≤ 600؛ البانر ×3؛ roles تالف |
| الإرسال (07) | 3 أوضاع؛ صوت يُرسل لجوجل مرة واحدة؛ reply chain |
| الجلسات (08) | كتابة مزدوجة؛ استمرار بعد restart؛ قبول صامت؛ إعادة بناء الفهرس |
| السجلات (09) | حجب؛ تدوير؛ ZIP بلا keys |
| الذاكرة (10) | strikes؛ صدى السياق؛ 503 ليس strike |
| اللوحة (11) | 64 بايت؛ parity؛ FSM TTL |
| الأمان (13) | توكن مولّد؛ reset POST فقط؛ rate limit |

### 4.2 البنية التحتية للاختبار
- **Mock provider** [ج2]: `FakeGemini` يُرجع سيناريوهات (`success`, `503`, `429 daily`, `timeout`, `blocked`, `echo_context`) بالترتيب المطلوب — **بلا شبكة**. موجود جزئياً في `tests/test_transcriber.py` عبر monkeypatch؛ يُعمَّم.
- **Fake Telegram**: يسجّل كل نداء API (method, payload) → اختبارات الإرسال/الأزرار تفحص التسلسل.
- **Mock clock**: `time.time`/`sleep` قابلان للحقن (الحلقة تستخدم `time` مباشرة الآن — يُستبدل بـ `clock` قابل للتبديل).
- **Golden set** [ج3]: 5–10 ملفات صوت قصيرة حقيقية + نصوص مرجعية → اختبار **يدوي** `tools/golden_check.py` يُشغَّل قبل الإصدار (يستهلك حصة؛ ليس في CI).
- CI: pyflakes + pytest على 3.10/3.12 ✔ موجود؛ يُضاف **حد أدنى للتغطية** لاحقاً (P2).

## 5. أعلام الميزات والنواة المحمية [ج3 constitution — نقبلها]
- كل ميزة جديدة خلف `FEATURE_<NAME>` في `Config` **افتراضي 0** حتى تُختبر على الاستضافة، ثم تُقلب 1 في إصدار لاحق.
- **النواة المحمية**: `transcriber.classify_response`, `key_manager` quota, `dynamic_read_timeout` — تعديلها يتطلب regression كاملاً + ذكر صريح في PR.
- **ميزانية التعقيد**: أي PR يضيف > 400 سطر صافٍ أو اعتماداً جديداً يحتاج تبريراً مكتوباً.
- `requests` يبقى الاعتماد الوحيد (zipfile/logging/sqlite3 من المكتبة القياسية).

## 6. تشغيل محلي + استضافة معاً
- نفس التوكن في مكانين → 409 Conflict. **الحل:** `INSTANCE_ROLE=primary|standby`؛ الـ standby يعمل ويب-فقط ويفحص `getMe`… **لا** — أبسط: المالك يشغّل محلياً **بتوكن بوت ثانٍ** (بوت تجريبي) من `keys.json` المحلي؛ التوثيق في `DEPLOY.md`. (409 الحالي يُبلَّغ مرة واحدة لا كل 10ث.)
- أسماء `.bat` العربية تبقى؛ `transcribe_tool.py` يستخدم نفس pipeline (قاموس/دور) اختيارياً بعلم `--plain`.

## 7. معايير القبول (DoD)
1. بدء بلا `WEB_ACCESS_TOKEN` على `0.0.0.0` → توكن مولّد ومطبوع؛ طلب بلا توكن → 401.
2. GET `/api/reset` → 405.
3. ملف JSON تالف لأي مخزن → بدء ناجح + ملف `.corrupt-*`.
4. كل `atomic_write_json` تُستدعى بدل `open(..., "w")` المباشر (grep في CI).
5. `FakeGemini`/`FakeTelegram` مستخدمان في ≥ 80% من الاختبارات الجديدة.
