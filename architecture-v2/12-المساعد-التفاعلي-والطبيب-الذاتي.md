# 12 — المساعد التفاعلي (`/ask`) والطبيب الذاتي (`/doctor`) ومخطِّط المشاريع

> **الهدف:** استغلال الحصص الوفيرة (flash-lite 500 RPD، antigravity 100 RPD) لإضافة ذكاء **نصي** حول التفريغ دون لمس حصة التفريغ.
> **المصادر:** [ج12] `/ask` `/chat`، [ج11] antigravity عبر Interactions API، [ج1] M12 self-healing `/doctor`، [ج3] تقرير حادث تلقائي، [شات] اختبار antigravity الحي.

---

## 1. `/ask` — مساعد الجلسة [ج12]

- `/ask <سؤال>` → السياق = ملف الجلسة النشطة (أو آخر جلسة) مقتطعاً إلى `ASK_MAX_CONTEXT_CHARS=12000` (الأحدث أولاً) + ملخص L2 → flash-lite بأقصى تفكير.
- الجواب يُرسل **ويُلحق** بملف الجلسة تحت `### 💡 استشارة ومساعد الجلسة [timestamp]` [قرار ج12].
- `/chat` = وضع متابعة: الأسئلة التالية خلال `CHAT_TTL=10` دقائق تحمل آخر 6 تبادلات؛ `/endchat` أو انتهاء المهلة.
- **ليس تفريغاً**: فويس أثناء `/chat` → يُفرَّغ طبيعياً؛ لا يُفسَّر كسؤال.
- `/ask` بلا جلسة → على آخر `N` مدخلات في `ALL.md` (أو نتائج `/find`).

### حدود واضحة [رأينا]
- flash-lite جيد للتلخيص/السؤال عن المحتوى، ليس للتخطيط الهندسي العميق.
- لا صلاحيات لتغيير إعدادات — عبر الأوامر فقط.
- الكلفة ≈ 1 نداء/سؤال → مهمل.

## 2. `/plan` — مخطِّط المشاريع عبر Antigravity [ج11]

- مدخل: نص (جلسة كاملة أو فويس) + طلب المالك "حوّل ده لخطة/مواصفة".
- **Interactions API**: `POST /v1beta/interactions` بجسم `{"agent":"antigravity-preview-latest","environment":"remote","input":"<prompt>"}` — **نص فقط** (الصوت → 400 كما اختبر المالك).
- خيط خلفي بمهلة `AGENT_TIMEOUT=180`؛ "⏳ Antigravity شغّال…" ثم النتيجة (طويلة → ملف `.md`).
- تُلحق بالجلسة تحت `### 🧭 خطة Antigravity`.
- 100 RPD/60 RPM — وفيرة؛ لا failover له (فشل → "جرّب لاحقاً").

> ⚠️ **تحذير:** Interactions API في `v1beta`/preview — قد يتغير الشكل. العميل معزول في `interactions_client.py` مع تحليل مرن للرد؛ فشله **لا يمس** أي شيء آخر.

## 3. `/doctor` — الطبيب الذاتي

### 3.1 الفحص المحلي (بلا AI) — **الأساس**
| الفحص | المصدر |
|---|---|
| نبض الـ poller (آخر poll ناجح منذ) | `STATE.last_poll_ok` |
| حجم الطابور + أقدم مهمة منتظرة | queue |
| حالة القواطع + أقرب فتح | `model_circuit.snapshot` |
| المتبقي من الحصة اليومية (تقديري) | `key_manager` |
| مفاتيح غير صالحة / بلا مجموعة مشروع | `keys.json` |
| قرص: مساحة، قابلية الكتابة، `.persist_probe` | `DATA_DIR` |
| حجم logs/sessions/backups vs السقوف | fs |
| `getMe` تليجرام (زمن الاستجابة) | API |
| ping لـ Gemini؟ **لا** — يستهلك حصة؛ نعرض `recent_attempts` بدلاً منه | `model_state` |
| إصدار Python، وقت التشغيل، عدد إعادات التشغيل | process |

→ تقرير ✅/⚠️/❌ في رسالة واحدة. **P1** — لا يحتاج AI.

### 3.2 التشخيص بالذكاء (زر "🧠 حلّل" اختياري)
- تقرير 3.1 + آخر 50 سطر خطأ **محجوبة الأسرار** → antigravity → تفسير + توصيات.
- **لا تنفيذ تلقائي لأي توصية** [رأينا — يخالف ج1 M12 "self-healing SIGTERM"]: الوكيل يقترح، المالك يقرر. أقصى أتمتة: زر "طبّق: /reset" يعرض الأمر ليضغطه المالك.
- `DOCTOR_INTERVAL_MIN=60` فحص دوري **صامت**؛ يُبلَّغ المالك فقط عند ❌ جديد.

### 3.3 تقرير الحادث التلقائي [ج3]
عند: stall > 90ث، أو ≥3 فشل متتالٍ، أو إعادة تشغيل الـ watchdog → `incidents/INC-YYYYMMDD-HHMM.md` تلقائياً (الخط الزمني من `events`، آخر أخطاء، حالة القواطع) + ملخص سطرين للمالك مع `/trace`. **P1** — كان سيوفر ساعات في الحوادث 02/03.

## 5. معايير القبول (DoD)
1. `/ask` يُلحق الجواب بالجلسة ويستخدم `TEXT_ASSIST_MODEL` فقط (اختبار يفحص اسم الموديل).
2. `/doctor` المحلي يعمل بلا شبكة لجوجل (mock) ويُكمل التقرير حتى لو فشل فحص واحد.
3. Interactions client: رد غير متوقع → رسالة واضحة لا استثناء غير معالج.
4. تقرير حادث يُنشأ عند stall مُحاكى ويحوي الخط الزمني.
