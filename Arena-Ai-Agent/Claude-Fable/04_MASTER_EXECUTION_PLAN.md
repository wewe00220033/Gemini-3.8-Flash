**(ج) `wrap_transcript` — تُضاف في `prompts.py`:**

```python
_TAG = "audio_transcript"
_OPEN = "<" + _TAG + ">"
_CLOSE = "<" + "/" + _TAG + ">"
_CLOSE_SAFE = "<" + "\\/" + _TAG + ">"


def wrap_transcript(text):
    """يغلّف الخام بوسم العزل. تكراري (idempotent) فقط عند تغليف صحيح من الطرفين."""
    t = str(text or "").strip()
    if t.startswith(_OPEN) and t.endswith(_CLOSE):
        return t
    safe = t.replace(_CLOSE, _CLOSE_SAFE)  # نسخة مؤقتة؛ الخام الأصلي لا يُمَس
    return _OPEN + "\n" + safe + "\n" + _CLOSE
```

- الفرق عن PLAN: `startswith/endswith` بدل `in` (H-02) — نص يذكر الوسم داخلياً يُغلَّف دائماً.
- الاستبدال النصي للإغلاق الداخلي ليس «حارساً»؛ هو تحييد على نسخة مؤقتة تُرسل للنموذج فقط.
- مواضع التطبيق: `prompts.py:360`، `text_assist.py:297`, `:417`, `:499`.
