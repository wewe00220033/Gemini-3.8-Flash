# 📁 مجلد زيزو — التوثيق المعماري والنموذج الذهبي ومقارنة الدفعات الـ 14

توثيق هندسي شامل لنتائج تدقيق ومقارنة تفريغات الفويس (50.4 ثانية) عبر مختلف النماذج، والقرارات المعمارية المعتمدة (`DEC-01` إلى `DEC-09`)، والنموذج الذهبي المرجعي، وخارطة طريق تطبيق أعلى جودة في الكود.

---

## 🗂️ فهرس الملفات داخل المجلد

- 📄 **1.MD:** سجل تفريغات الدفعات الـ 14 الميدانية، ومقارنة المخرجات بين النماذج (`gemini-3.5-transcribe`، `gemini-3.6-flash`، `OpenAI/Shelby`)، ورصد مشكلات التحريف والتخمين وتداخل المتكلمين.
- 📄 **2.MD:** المراجعة المعمارية الشاملة بالأسطر، والقرارات الهندسية التسعة (`DEC-01` إلى `DEC-09`)، وتحليل ثغرة رفض الخدمة بالدفعة #8، وقواعد العمل المشتركة.
- 📄 **README.md:** هذا الدليل الشامل؛ يلخّص النموذج الذهبي المرجعي وخارطة الطبقات الخمس لتنفيذ الجودة في السكربت.

## 🌟 النموذج الذهبي المرجعي المقارن (Reference Benchmark)

### المرحلة 1: النص الخام الفعلي المسجل من الموديل
```text
خليه يعمل ايه يعمل جيف دوت ماشي جربه فيه كده بس قوله ابعتله ايه بقى قوله ابعتله اللي هو بتاع البروكسي والايميلات وبتاع التيمب وقله خش اعمل سكريبت يسحب الاي بي كي وبتاع ويخزنه ويفضل يسحب في اي بي كي وبين كل واحد والتاني بروكسي وبس متقولوش تفاصيل عايز بس اتاكد ان هو هيفتح المتصفح ويدور ويجيب ويجيب من هنا وهنا تمام بس دي اللي عايزك تختبرها وتقولي الدنيا تمام فيه قول تاني معلش على مهلك كده بس على مهلك مش مستعجلين قول كده تاني على مهلك بس كده هتديله الموقع اه ماشي اديله الموقع قوله الموقع ده اعمل عليه عايز اجمع توكنات اللي جوه الاي بي كي اللي جوه هتاخد هتعملي سكريبت يفضل يجمع في توكنات عندك اهي ايميلات مؤقته تيمب وعندك بروكسي استخدم المناسب عشان تتفادى الحظر وافتح المتصفح وهات الايميل وهات الباسورد وافهم الموقع شغال ازاي وشوف هتسحب منه الاي بي كي ازاي وسجل عندك في ملف الجيسون
```

### المرحلة 2: النص الخام المتوقع بعد تفعيل القاموس المسبق (Layer 0)
```text
خليه يعمل إيه؟ يعمل «جيف دوت» [؟]. ماشي، جرّبه فيه كده بس. قوله: ابعت له إيه بقى؟ قوله ابعت له اللي هو بتاع الـ Proxy والإيميلات وبتاع الـ Temp. وقله: خش اعمل Script يسحب الـ API Key وبتاع ويخزّنه، ويفضل يسحب في API Key، وبين كل واحد والتاني Proxy، وبس متقولوش تفاصيل. عايز بس أتأكد إن هو هيفتح المتصفح ويدوّر ويجيب من هنا وهنا، تمام؟ بس دي اللي عايزك تختبرها وتقولي الدنيا تمام فيه.
— قول تاني معلش، على مهلك كده، بس على مهلك، مش مستعجلين، قول كده تاني على مهلك بس كده.
— هتدّي له الموقع.
— آه، ماشي.
— ادّي له الموقع، قوله: الموقع ده اعمل عليه، عايز أجمع Tokens اللي جوه الـ API Key اللي جوه، هتعمل لي Script يفضل يجمع في Tokens. عندك أهي إيميلات مؤقتة Temp، وعندك Proxy؛ استخدم المناسب عشان تتفادى الحظر، وافتح المتصفح، وهات الإيميل وهات الباسورد، وافهم الموقع شغال إزاي، وشوف هتسحب منه الـ API Key إزاي، وسجّل عندك في ملف الـ JSON.
```

### المرحلة 3: الرسالة النهائية المنظمة في تليجرام (Golden Reference Delivery)
```text
📌 **اختبار Script لسحب الـ API Key والـ Tokens وتخزينها في ملف JSON**

**المتكلم 1:** خليه يعمل إيه؟ يعمل «جيف دوت» [؟]. ماشي، جرّبه فيه كده بس. قوله: ابعت له إيه بقى؟ قوله ابعت له اللي هو بتاع الـ Proxy والإيميلات وبتاع الـ Temp. وقله: «خش اعمل Script يسحب الـ API Key وبتاع ويخزّنه، ويفضل يسحب في API Key، وبين كل واحد والتاني Proxy». وبس، متقولوش تفاصيل.

عايز بس أتأكد إن هو هيفتح المتصفح ويدوّر ويجيب من هنا وهنا، تمام؟ بس دي اللي عايزك تختبرها وتقولي الدنيا تمام فيه.

**المتكلم 2:** قول تاني معلش، على مهلك كده، بس على مهلك، مش مستعجلين. قول كده تاني على مهلك بس كده.

**المتكلم 1:** هتدّي له الموقع.

**المتكلم 2:** آه، ماشي.

**المتكلم 1:** ادّي له الموقع، قوله: «الموقع ده اعمل عليه، عايز أجمع Tokens اللي جوه الـ API Key اللي جوه. هتعمل لي Script يفضل يجمع في Tokens. عندك أهي إيميلات مؤقتة Temp، وعندك Proxy؛ استخدم المناسب عشان تتفادى الحظر. وافتح المتصفح، وهات الإيميل وهات الباسورد، وافهم الموقع شغال إزاي، وشوف هتسحب منه الـ API Key إزاي، وسجّل عندك في ملف الـ JSON».

🔹 **النقاط والملاحظات الجوهرية:**
• الهدف اختبار قدرة الوكيل على فتح المتصفح والبحث وسحب الـ API Key من الموقع تلقائياً.
• استخدام إيميلات مؤقتة Temp وتدوير الـ Proxy بين العمليات لتفادي الحظر.
• استخراج الـ Tokens وتخزين النتائج بصيغة JSON دون إعطاء تفاصيل مسبقة للأداة.

📍 **الخريطة الذهنية للموضوع:**
اختبار سحب الـ API Key
├── الإعداد وتجهيز البيئة
│   ├── إيميلات مؤقتة Temp
│   └── تدوير الـ Proxy
├── مهام الـ Script الآلي
│   ├── تصفح الموقع وفهم بنيته
│   ├── استخراج الـ API Key
│   └── جمع وتخزين الـ Tokens
└── مخرجات التنفيذ
    ├── تخزين البيانات في ملف JSON
    └── التحقق من تفادي الحظر
```

## 🛠️ خارطة طريق التطبيق الهندسي (5 حلقات مترابطة)

- 🔹 **الحلقة الأولى — القاموس المسبق (Layer 0):**
  - ملفات: `glossary.py` و `glossary.json`.
  - الإجراء: تبديل `الاي بي كي` إلى `API Key`، وفصل المفرد `Token` عن الجمع `Tokens`، وإضافة `Script` و `Proxy` و `Temp` و `JSON`.
  - معالجة السوابق: `الـ API Key` مقابل مسافة لواو العطف `و Proxy` (منع الالتصاق الخاطئ `وـ`).
  - رفع سقف `hints_for_prompt(limit=8)` إلى `20` لوصول المصطلحات لطبقة الصوت.

- 🔹 **الحلقة الثانية — طبقة التفريغ الصوتي (Layer A):**
  - ملفات: `config.py` و `prompts.py`.
  - الإجراء: تثبيت العشوائية `TEMPERATURE = 0.1` لمنع التأليف السمعي.
  - إدراج 4 قواعد مكثفة ضمن حد 600 حرف (`TRANSCRIBE_LAYER_A_MAX_CHARS`): التفريق بين `API Key` و `.apk`، البدء من ثانية `00:00`، منع الإكمال التلقائي العامي، وفصل المتكلمين بـ `— ` خفيف.

- 🔹 **الحلقة الثالثة — العنوان الذكي (Smart Title):**
  - ملفات: `delivery.py` و `sessions.py`.
  - الإجراء: تمرير النص عبر القاموس قبل حساب العنوان لمنع استنتاج `APK`، وتوحيد حالة الإنجليزية (`Script` / `Tokens` / `API Key`)، وتنقية الرموز في العنوان البديل.

- 🔹 **الحلقة الرابعة — العزل بالوسوم وبرومبتات التنظيم والسبك (Layer B & Synthesizer):**
  - ملفات: `prompts.py` و `text_assist.py` و `.local/shelby_polish.py`.
  - الإجراء: تغليف النص بـ `<audio_transcript>...</audio_transcript>` لحل رفض شلبي من جذوره.
  - تعريف دور المحرك كـ **Passive ASR Post-Editor** لمنع التحريف الأخلاقي والمواعظ والرفض واقتراح البدائل.
  - ضبط القواعد الـ 10: المحافظة على ردود التأكيد القصيرة لمنع دمج المتكلمين، تنظيف اللعثمة (`ويجيب ويجيب` ← `ويجيب`)، ضبط إملاء العامية (`فيه` vs `في`)، قصر `[؟]` على أول ذكر فقط، وشجرة الخريطة الذهنية `📍` بسطور مكثفة `<= 32` حرف.

- 🔹 **الحلقة الخامسة — الاختبارات التلقائية وصمامات الأمان:**
  - ملفات: `tests/test_transcriber.py` و `tests/test_pipeline_phase3.py`.
  - الإجراء: تحديث اختبارات الحرارة، والتحقق من بقاء تلميحات طبقة A دون 600 حرف، وتغطية استبدالات القاموس وعزل الوسوم.
