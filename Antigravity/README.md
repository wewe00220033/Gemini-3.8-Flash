## 🏛️ المبادئ الحاكمة للمنظومة

1. **الحقيقة المجردة بالسطور (Ground Truth):** الاعتماد فقط على كود المشروع الحقيقي واختباراته وفحص سطوره دون افتراضات أو تخمينات.
2. **عزل الأسرار 360° (Zero-Leakage):** كل ما يحوي كوكيز، توكنات، جلسات، أو بيانات اعتماد يعيش محلياً فقط خارج نطاق Git وبعيداً عن أي مستودع عام.
3. **فصل الطبقات الصارم (Decoupled Architecture):** طبقة التفريغ الصوتي (Layer A) محصنة ومستقلة تماماً بحراسها، واستبدال أو تعطل طبقة التنظيم النصي (Layer B) يستحيل أن يعطل وصول النص الخام للمستخدم.
4. **التبديل التلقائي الذكي (Auto Failover):** استدعاء المزود المحلي بمهلة زمنية صارمة (10-15 ثانية)، وفي حال التأخر أو الفشل يتم التحويل الفوري إلى `gemini-3.5-flash-lite` مع إنهاء العملية المعلقة فوراً لمنع تسريب الرام.
